InterviewAI

AI-powered mock interview platform built with React, Node.js, Express, MongoDB, and AI.

Included features
AI resume analysis
Personalized interview questions
Technical interview
HR interview
Full mock interview
Coding challenges
Code output prediction
AI answer evaluation
Performance analysis
Interview history
Firebase authentication
Interactive AI interviewer
Multiple AI providers (Gemini, OpenAI, OpenRouter)
MongoDB persistence
REST API
Run on Windows
git clone https://github.com/Anupama-Sen24/interviewAI.git
cd interviewAI

npm install
cd client
npm install

cd ../server
npm install

Create the required .env files for MongoDB, Firebase, and your AI API key.

Start the application

From the root folder:

npm run dev

Frontend:

http://localhost:5173

Backend:

http://localhost:5000
